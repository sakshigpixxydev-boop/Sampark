# Deployment Guide

## Overview

This guide provides instructions for deploying the Pramukh Sankalp School Management System to production and staging environments.

## Prerequisites

### Server Requirements

- **Operating System**: Ubuntu 20.04 LTS or higher / CentOS 8 or higher
- **Web Server**: Nginx 1.18+ or Apache 2.4+
- **PHP**: 8.2 or higher
- **Database**: MySQL 8.0+ or MariaDB 10.5+
- **Memory**: Minimum 2GB RAM (4GB recommended)
- **Storage**: Minimum 20GB (50GB recommended)
- **SSL Certificate**: Required for production

### PHP Extensions Required

```bash
php8.2-cli
php8.2-fpm
php8.2-mysql
php8.2-mbstring
php8.2-xml
php8.2-bcmath
php8.2-curl
php8.2-zip
php8.2-gd
php8.2-intl
```

### Additional Software

- Composer 2.x
- Node.js 18.x or higher
- npm 9.x or higher
- Git
- Supervisor (for queue workers)

## Environment Setup

### 1. Clone Repository

```bash
cd /var/www
git clone <repository-url> pramukh-sankalp
cd pramukh-sankalp
```

### 2. Install Dependencies

```bash
# Install PHP dependencies
composer install --no-dev --optimize-autoloader

# Install Node dependencies
npm install

# Build assets
npm run build
```

### 3. Configure Environment

```bash
# Copy environment file
cp .env.example .env

# Generate application key
php artisan key:generate
```

### 4. Configure .env File

Edit `.env` file with production settings:

```env
APP_NAME="Pramukh Sankalp"
APP_ENV=production
APP_KEY=base64:... # Generated by key:generate
APP_DEBUG=false
APP_URL=https://your-domain.com

LOG_CHANNEL=stack
LOG_LEVEL=error

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=pramukh_sankalp
DB_USERNAME=your_db_user
DB_PASSWORD=your_secure_password

BROADCAST_DRIVER=log
CACHE_DRIVER=file
FILESYSTEM_DISK=local
QUEUE_CONNECTION=database
SESSION_DRIVER=database
SESSION_LIFETIME=120

MAIL_MAILER=smtp
MAIL_HOST=smtp.mailtrap.io
MAIL_PORT=2525
MAIL_USERNAME=your_username
MAIL_PASSWORD=your_password
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS="noreply@your-domain.com"
MAIL_FROM_NAME="${APP_NAME}"

# Error Tracking (Sentry)
SENTRY_LARAVEL_DSN=your_sentry_dsn
SENTRY_TRACES_SAMPLE_RATE=0.2

# File Upload Limits
UPLOAD_MAX_FILESIZE=10M
POST_MAX_SIZE=10M
```

### 5. Set Permissions

```bash
# Set ownership
sudo chown -R www-data:www-data /var/www/pramukh-sankalp

# Set directory permissions
sudo find /var/www/pramukh-sankalp -type d -exec chmod 755 {} \;

# Set file permissions
sudo find /var/www/pramukh-sankalp -type f -exec chmod 644 {} \;

# Set storage and cache permissions
sudo chmod -R 775 /var/www/pramukh-sankalp/storage
sudo chmod -R 775 /var/www/pramukh-sankalp/bootstrap/cache
```

## Web Server Configuration

### Nginx Configuration

Create `/etc/nginx/sites-available/pramukh-sankalp`:

```nginx
server {
    listen 80;
    listen [::]:80;
    server_name your-domain.com www.your-domain.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    listen [::]:443 ssl http2;
    server_name your-domain.com www.your-domain.com;
    root /var/www/pramukh-sankalp/public;

    # SSL Configuration
    ssl_certificate /etc/ssl/certs/your-domain.crt;
    ssl_certificate_key /etc/ssl/private/your-domain.key;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;

    # Security Headers
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;
    add_header Referrer-Policy "no-referrer-when-downgrade" always;
    add_header Content-Security-Policy "default-src 'self' http: https: data: blob: 'unsafe-inline'" always;

    index index.php;

    charset utf-8;

    # Logging
    access_log /var/log/nginx/pramukh-sankalp-access.log;
    error_log /var/log/nginx/pramukh-sankalp-error.log;

    # File Upload Limits
    client_max_body_size 10M;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location = /favicon.ico { access_log off; log_not_found off; }
    location = /robots.txt  { access_log off; log_not_found off; }

    error_page 404 /index.php;

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.2-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
        fastcgi_hide_header X-Powered-By;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}
```

Enable the site:

```bash
sudo ln -s /etc/nginx/sites-available/pramukh-sankalp /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

### Apache Configuration

Create `/etc/apache2/sites-available/pramukh-sankalp.conf`:

```apache
<VirtualHost *:80>
    ServerName your-domain.com
    ServerAlias www.your-domain.com
    Redirect permanent / https://your-domain.com/
</VirtualHost>

<VirtualHost *:443>
    ServerName your-domain.com
    ServerAlias www.your-domain.com
    DocumentRoot /var/www/pramukh-sankalp/public

    # SSL Configuration
    SSLEngine on
    SSLCertificateFile /etc/ssl/certs/your-domain.crt
    SSLCertificateKeyFile /etc/ssl/private/your-domain.key

    # Security Headers
    Header always set X-Frame-Options "SAMEORIGIN"
    Header always set X-Content-Type-Options "nosniff"
    Header always set X-XSS-Protection "1; mode=block"

    <Directory /var/www/pramukh-sankalp/public>
        Options -Indexes +FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>

    # Logging
    ErrorLog ${APACHE_LOG_DIR}/pramukh-sankalp-error.log
    CustomLog ${APACHE_LOG_DIR}/pramukh-sankalp-access.log combined
</VirtualHost>
```

Enable the site:

```bash
sudo a2ensite pramukh-sankalp
sudo a2enmod rewrite ssl headers
sudo systemctl reload apache2
```

## Queue Worker Setup

### Configure Supervisor

Create `/etc/supervisor/conf.d/pramukh-sankalp-worker.conf`:

```ini
[program:pramukh-sankalp-worker]
process_name=%(program_name)s_%(process_num)02d
command=php /var/www/pramukh-sankalp/artisan queue:work database --sleep=3 --tries=3 --max-time=3600
autostart=true
autorestart=true
stopasgroup=true
killasgroup=true
user=www-data
numprocs=2
redirect_stderr=true
stdout_logfile=/var/www/pramukh-sankalp/storage/logs/worker.log
stopwaitsecs=3600
```

Start the worker:

```bash
sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl start pramukh-sankalp-worker:*
```

## Backup Strategy

### Database Backup Script

Create `/usr/local/bin/backup-pramukh-db.sh`:

```bash
#!/bin/bash

BACKUP_DIR="/var/backups/pramukh-sankalp"
DATE=$(date +%Y%m%d_%H%M%S)
DB_NAME="pramukh_sankalp"
DB_USER="pramukh_user"
DB_PASS="your_password"

mkdir -p $BACKUP_DIR

# Full backup
mysqldump -u $DB_USER -p$DB_PASS $DB_NAME | gzip > $BACKUP_DIR/db_backup_$DATE.sql.gz

# Remove backups older than 30 days
find $BACKUP_DIR -name "db_backup_*.sql.gz" -mtime +30 -delete

echo "Backup completed: db_backup_$DATE.sql.gz"
```

Make executable:

```bash
sudo chmod +x /usr/local/bin/backup-pramukh-db.sh
```

Add to crontab:

```cron
0 2 * * * /usr/local/bin/backup-pramukh-db.sh >> /var/log/pramukh-backup.log 2>&1
```

### File Backup

```bash
# Backup storage directory
tar -czf /var/backups/pramukh-sankalp/storage_$(date +%Y%m%d).tar.gz \
    /var/www/pramukh-sankalp/storage
```

## Rollback Procedure

If deployment fails:

```bash

php artisan down

# Revert to previous version
git reset --hard <previous-commit-hash>

# Restore dependencies
composer install --no-dev

# Rollback database (if needed)
php artisan migrate:rollback --force

# Clear and rebuild caches
php artisan cache:clear
```

## Troubleshooting

### Common Issues

**500 Internal Server Error**
- Check error logs: `/var/www/pramukh-sankalp/storage/logs/laravel.log`
- Verify file permissions
- Check `.env` configuration
- Clear caches

**Database Connection Error**
- Verify database credentials in `.env`
- Check MySQL service status: `sudo systemctl status mysql`
- Test connection: `mysql -u username -p`

**Queue Jobs Not Processing**
- Check supervisor status: `sudo supervisorctl status`
- View worker logs: `/var/www/pramukh-sankalp/storage/logs/worker.log`
- Restart workers: `sudo supervisorctl restart pramukh-sankalp-worker:*`

**High Memory Usage**
- Check PHP memory limit in `php.ini`
- Optimize database queries
- Enable OPcache
- Consider upgrading server resources
